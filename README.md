# RPmanaGer
Um sistema para gerenciar (adicionar, editar e excluir registros) de entidades em mesas de RPG:
Entidades: Personagens, Inimigos e Coadjuvantes.
Tecnologias: JSP, Gson, JSON e Tomcat.
Diagrama: Diagrama Imagem do diagrama de classes (sugestão: draw.io, gratuito)

Como executar o projeto: Entre no Eclipse e clone o repositório.
